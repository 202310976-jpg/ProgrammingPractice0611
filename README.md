# 1. 서비스 개요

많은 사람들이 운동 전후 올바른 스트레칭의 차이와 중요성을 모른 채 운동을 시작합니다.

운동 전에는 체온을 높이고 관절 가동 범위를 확장하는 동적 스트레칭이 필수적입니다.

반면, 제자리에 멈춰 근육을 늘리는 정적 스트레칭은 운동 전에 수행할 경우 근원섬유의 탄성력을 떨어뜨려 순간 근력을 약 2.5% 상실시키고 부상 위험을 도리어 가중시킵니다.

본 서비스는 사용자가 이러한 생리학적 차이를 쉽게 이해하고, 자신의 운동 상황에 맞는 정확한 스트레칭 처방을 즉시 활용할 수 있도록 돕기 위해 기획되었습니다.

# 2. 명확한 목표 사용자 정의

본 서비스는 사용자의 훈련 목적에 따라 대상자를 아래와 같이 두 가지 유형으로 구분합니다.

1. 운동 중인 사용자

목표: 운동 전후 부상을 방지하고 효율성을 극대화하기 위해, 당일 진행할 부위별 맞춤형 스트레칭 정보와 동작 시연 동영상 링크를 현장에서 빠르게 확보하여 수행하는 것.

2. 예방 및 학습 목적의 사용자

목표: 특정 관절이 강직되어 있을 때 나타나는 생체역학적 보상 작용과 잘못된 준비운동이 유발하는 실제 스포츠 손상 사례를 학습하여 장기적인 부상 위험을 선제적으로 통제하는 것.

# 3. 핵심 기능 우선순위 설계

본 서비스는 사용자 요구의 긴급성과 시스템 완성도를 기준으로 기능을 세 단계로 분류하여 설계했습니다.

1순위: 사용자 상황(운동 전/후) 및 목표 부위(상체/하체) 맞춤형 스트레칭 처방 가이드 및 시연 영상 자동 매칭 기능

2순위: 각 스트레칭 동작 시 작용하는 신체 관절 범위 분석 및 해부학적 유연성 향상 정보 제공 기능

3순위: 올바르지 못한 준비운동 및 강행으로 발생하는 실제 임상 부상 사례 아카이브 구축 및 대처 프로토콜 제공 기능

# 4. 사용자 여정 시나리오

시나리오 1: 하체 운동(러닝) 전후 스트레칭 처방 탐색 케이스

퇴근 후 하체 유연성이 부족한 초보 러너가 야외 야간 러닝을 시작하기 전과 마친 직후에 웹앱을 활용하는 단계입니다.

진행 과정:

사용자가 메인 화면에서 '운동 전 스트레칭 가이드'를 클릭해 처방 전용 창으로 이동합니다.

전용 창에서 오늘 훈련할 부위인 '하체'를 선택하면, 웜업용 동적 스트레칭 가이드와 시연 동영상이 화면에 매칭되어 나옵니다.

운동이 끝난 후 다시 접속하여 '운동 후 스트레칭 가이드'를 통해 하체 피로를 완전히 풀어주는 정적 스트레칭을 확인하고 완벽히 마무리합니다.

시나리오 2: 벤치프레스 전 웜업 탐색 및 실제 부상 사례 학습 케이스

가슴 단련을 위해 고중량 벤치프레스를 전개하려는 중급 리프터가 어깨를 보호하기 위해 예방 정보를 찾아보는 단계입니다.

진행 과정:

가슴 운동 전에 어깨를 풀기 위해 앱에서 '상체'를 선택하고 회전근개를 깨우는 동적 가이드와 영상을 가볍게 봅니다.

무작정 무거운 무게를 들기 전에 다치면 안 되니까, 화면을 아래로 내려서 실제 부상 사고 데이터를 확인해 봅니다.

실제로 발생한 무시무시한 가슴 근육 파열 사례를 보고, 다치지 않기 위해 어깨를 단단히 고정하고 등 뒤를 풀어주는 예방 루틴을 적용합니다.

실제 한국 부상 사례 (대흉근 완전 파열):

사례 요약: 국내 웨이트 트레이닝 동호인 사이에서 고중량 벤치프레스를 수행할 때 가장 심각하게 보고되는 부상 중 하나입니다. 가슴과 어깨 관절 부위의 충분한 동적 스트레칭을 생략한 채 차가운 상태의 근섬유로 자신의 한계 중량을 무리하게 낮추다 발생했습니다.

부상 메커니즘: 가슴 근육인 대흉근이 충분히 유연해지지 않은 상태에서 바벨이 가슴 쪽으로 하강하자, 가슴 근육이 강한 하중 장력을 견디지 못하고 상완골(어깨 뼈) 접합부 힘줄 부분에서 뚝 소리와 함께 완전히 뜯어져 이탈했습니다.

결과 및 조치: 해당 환자는 즉각 수술실에서 뜯어진 대흉근 힘줄을 인공 나사못을 이용해 어깨뼈에 다시 봉합하는 큰 수술을 진행했으며, 6개월간 일상생활 고정과 재활 치료를 수반하는 극심한 마비를 겪었습니다.

부상 예방을 위한 추가 가이드 프로토콜:

견갑골의 능동 하강 통제: 바벨을 밀어 올리기 전 어깨 뼈를 벤치 바닥 쪽으로 강하게 고정하여 상완골 머리와 가슴 인대가 불필요하게 앞으로 돌출되는 것을 역학적으로 방지합니다.

흉추 가동성 확보: 등 상부 척추의 가동각이 잠겨 있으면 바벨이 가슴에 닿을 때 대흉근 힘줄이 과도하게 신장되므로, 운동 전에 폼롤러 등을 이용해 등 뒤쪽의 신전 유연성을 미리 열어두어야 합니다.

# 5. 특이 케이스: 첫 사용자용 온보딩 및 튜토리얼 설계

처음 방문한 사용자에게는 웰컴 모달창을 띄워 신체 가동성 인지의 중요성을 바로 이해하게 돕고, '다시 띄우지 않기' 설정으로 재방문 시 메인 제어창이 곧바로 열리도록 설계했습니다.
'사이트 튜토리얼'을 누르면 운동 전후 스트레칭의 차이점, 보상 하중이 주는 위험 원리와 타겟 분류 설명이 직관적인 요약 페이지로 유연하게 연결됩니다.
