1. 서비스 개요 및 목적 (Introduction)

많은 초보 운동자들은 운동 전 부상 방지를 위해 제자리에 가만히 멈춰 근육을 늘리는 '정적 스트레칭'을 무작정 수행하곤 합니다. 그러나 이는 생체역학적으로 근원섬유의 탄성력을 저하시키는 원인이 됩니다. 연구에 따르면 운동 직전의 과도한 정적 스트레칭은 순간적인 근동원력(Muscle Force)을 약 $2.5\%$ 가량 즉각 손실시키며, 관절의 능동적 지지 성능을 약화시켜 도리어 부상률을 증가시키는 주요 원인이 됩니다.

FlexiRoutine Pro는 사용자가 자신의 신체 관절 가동성(Mobility) 한계를 인지하지 못한 채 고중량 스쿼트/데드리프트 등의 바벨 운동을 수행하다가, 인접 관절이 대신 움직이는 '관절 사슬 보상 작용(Joint Chain Compensation)'에 의해 요추(허리)에 정상치 대비 $150\%$ 이상의 비정상 전단 하중 부상을 입는 악순환을 예방하고자 설계된 과학적 헬스테크 웹앱입니다.

본 웹앱은 서비스를 처음 방문한 사용자도 복잡함 없이 시스템 목적을 이해할 수 있는 튜토리얼 흐름을 가집니다. 사용자의 상태 입력에 맞춰 정밀한 동적/정적 루틴 처방을 '독립된 새 창'으로 라우팅하고, 관절별 정상 가동 범위 수치 및 실제 스포츠 손상 사례 아카이브를 모달 컴포넌트로 결합하여 스포츠 안전을 제어하는 인터랙티브 처방 시스템을 지향합니다.

2. 명확한 목표 사용자 정의 (Target User Segments)

본 서비스는 사용자의 훈련 목적과 신체적 상태에 따라 타겟층을 아래와 같이 명확히 이원화하여 개별화된 솔루션을 제공합니다.

👤 A그룹: 정보 탐색형 입문자 (Information-Seeking Beginners)

정의: 웨이트 트레이닝 및 러닝을 이제 막 시작하여 부상 없이 안전하게 수행할 수 있는 올바른 웜업 루틴 순서와 생리학적 동작 원리를 체계적으로 정립하고자 하는 사용자.

사용 시나리오: "스쿼트를 하고 싶은데 운동 전에 정확히 어떤 스트레칭을 내 몸에 맞춰 배치해야 안전한지 웜업 순서와 메커니즘을 제대로 배우고 싶다."

👤 B그룹: 통증 인지형 초보자 (Pain-Experiencing Beginners)

정의: 특정 핵심 관절(발목/고관절/어깨)의 가동성 제한 상태를 모른 채 운동을 지속하다가, 스쿼트 하단 및 오버헤드 프레스 구간 등에서 무릎 통증, 골반 찝힘, 허리 통증을 겪는 사용자.

사용 시나리오: "스쿼트 시 자꾸 무릎이 아프고 뒤꿈치가 뜬다. 내 몸의 어느 관절이 잠겨 있어서 이 통증이 유발되는지 자가테스트로 검증하고 정밀한 재활 처방을 즉시 받고 싶다."

3. 핵심 기능 우선순위 설계 (Triage & Architecture)

교수님의 MVP(최소 기능 제품) 설계 가이드라인을 완벽히 수용하여, 단순 텍스트 나열을 배제하고 인터랙티브한 새 창(Sub-page) 분리 아키텍처 및 자가진단/임상 재활 모달 통제 장치를 구현했습니다.

🥇 1순위 (Must-Have): 사전 입력(Pre-fill) 연동형 맞춤 스트레칭 가이드 새 창 (Detail Window)

사전 연동 분기 기술: 메인 게이트웨이 화면에서 사용자가 타이밍 카드(1. 운동 전 가이드 / 2. 운동 후 가이드)를 터치하면, 해당 데이터가 시스템 백엔드에 자동으로 사전 기입(Pre-filled Matrix)된 전용 처방 새 창으로 즉시 화면이 전환됩니다.

생체역학적 안전 통제: 12주차 수업 규칙에 따라 운동 전 선택 시 최대 힘 출력을 저하시키는 정적 스트레칭을 완벽 배제하고 관절 윤활액을 공급하는 동적 스트레칭(Dynamic Warm-up)을 처방하며, 운동 후 선택 시 지친 근섬유 복원을 위한 정적 스트레칭(Static Cool-down)과 외부 임베드 비디오를 자동 연동합니다.

인터랙티브 타이머: 동작 유지 및 수행 상태를 시각적으로 카운트다운해 주는 30초 실시간 소리 타이머와 생체역학적 큐잉(Cueing)이 렌더링됩니다.

🥈 2순위 (Should-Have): 각 스트레칭별 작용 부위 및 해부학 지표 정보실 (Area 03)

메인창 하단(Bottom Fold) 스크롤 시 접근할 수 있는 영역으로, 핵심 관절(발목 / 고관절 / 어깨) 선택 토글 컴포넌트를 제공합니다.

각 관절별 정상 가동 범위 수치(예: 발목 배측굴곡 $20^\circ \sim 25^\circ$) 및 가동성 한계 상태로 고중량 리프팅을 강행할 시 타 관절로 분산 전이되는 요추 보상 압박 하중 수치($150\%$)를 과학적 근거 하에 보여줍니다.

"해부학 상세 지침 보기" 버튼 클릭 시, 자가 진단 평가 방법(Knee-to-Wall, Thomas, Scratch Test)과 정밀 임상 해설을 포함하는 모달 팝업창이 활성화됩니다.

🥉 3순위 (Could-Have): 스포츠 손상 사고 위험 통제 및 임상 재활 프로토콜 아카이브 (Area 04)

무지한 상태에서의 웨이트 트레이닝 및 과반동 스트레칭으로 인해 실제 정형외과 및 임상 현장에서 자주 일어나는 실제 부상 사례들(아킬레스건 부분 파열, 요추 4·5번 급성 인대 파열 등)을 독립 데이터 카드로 보관합니다.

"임상 재활 프로토콜 보기" 모달 장치를 결합하여, 통상 예상 회복 기간(예: 부분 파열 시 최소 12주 이상 고정), 현장에서 사수해야 할 3대 안전 수칙 리스트, 그리고 치료 후 단계별 능동 재활 프로토콜 가이드를 제공하여 무방비한 손상을 원천적으로 차단합니다.

4. 사용자 여정 시나리오 및 예외 처리 (Scenarios)

🗺 튜토리얼 및 온보딩 시나리오 (First-Time Visit Loop)

최초 진입: 브라우저 진입 시 사용자가 처음인지 확인하는 웰컴 팝업창이 강제 활성화됩니다.

세션 유지 기능: '다시 띄우지 않기' 체크 박스 활성화 시, 로컬 저장소(localStorage)에 바이패스 상태(bypassWelcomeModal: true)가 세션 데이터로 저장되어 다음 접속부터는 즉시 메인창으로 바로 도달합니다.

가이드 라우팅 단추: '사이트 튜토리얼' 버튼 클릭 시 퀵 내비게이션 카드 및 생리학적 서비스 배경 설명 대시보드로 이동합니다.

🗺 화면 분할 및 스크롤 이원화 시나리오 (Scroll-Down Framework)

메인 화면 최초 로딩 시 사용자의 인지 과부하를 막기 위해 상단 영역(Top Fold)에는 오직 1, 2구역인 [운동 전/후 가이드 게이트웨이] 대형 카드만 전면에 선명히 노출됩니다.

사용자가 브라우저를 아래로 직접 스크롤(Scroll Down)해야만 지식 정보 아카이브 영역인 [3구역: 관절별 해부학 정보실]과 [4구역: 부상 사고 아카이브 센터]가 슬라이딩 레이아웃으로 열립니다.

⚠️ 누락 예외 처리 종속 흐름 (Nested Exception Handling)

상황: 메인 게이트웨이 카드를 클릭해 새 창에 정상 진입했으나, 상세 타겟 부위(상체 / 하체)를 아무것도 지정하지 않은 상태에서 추천을 요구하는 경우.

시스템 예외 통제: 빈 화면이 노출되어 데이터 레이아웃이 깨지거나 런타임 Null Pointer 크래시가 유발되는 것을 전면 차단하고, 화면 중앙에 경고 일러스트와 함께 ⚠️ [예외 경고 통제 장치 작동: 운동 부위 및 타이밍 입력 누락] 안내 컴포넌트를 동적으로 렌더링하여 사용자 조작의 실수를 유연하게 복구하도록 설계했습니다.

5. AI Co-Engineering & 엔지니어링 주도성 기록 (AI 사용 내역서)

교수님의 투명성 가이드라인을 완벽히 준수하여 작성한 AI 사용 기록 및 본인의 주도적 판단/수정 내역입니다 (최소 4줄 이상 필수 조건 충족).

AI 프롬프트 활용: 웹앱의 웰컴 오버레이 팝업, 콤보 박스 분기 함수, 타이머 잔여 상태 루프 및 Tailwind CSS 반응형 레이아웃 초안 설계를 AI에게 요청하여 개발 생산성을 확보했습니다.

인간의 주도적 디버깅 (1) - 유튜브 임베드 차단 에러 우회: AI가 무작위로 매칭해 준 유튜브 링크들이 저작권 및 퍼가기 차단 정책(Error 153, Iframe Embedding Block)으로 인해 재생되지 않는 맹점을 디버깅 과정에서 발견했습니다. 외부 사이트 공유 및 타 플랫폼 탑재를 완전 수락하도록 풀어둔 물리치료/피트니스 전문 공식 채널의 스트레칭 비디오 아이디(_hyJjSGJAEo, Jaw7LUmEkBk, OcDhmXXgi8Q, UIRTPXj1Q1U)들을 직접 서치 및 검증하여, 라우팅 매칭 테이블에 안전한 미디어 파이프라인을 인간의 판단 하에 직접 구축하였습니다.

인간의 주도적 디버깅 (2) - 생리학적 오류 정정: AI가 작성한 초안 코드 중 운동 직전 웜업 단계에 '정적 스트레칭(차일드 포즈, 삼두 이완)'을 매칭하는 치명적인 과학적 부작용 결함을 발견했습니다. 운동 전 근동원력 $2.5\%$ 감소 리스크를 예방하기 위해, 본인이 12주차 수업 규칙과 생체역학 원리를 직접 적용하여 운동 전에는 오직 '동적 스트레칭'만 매칭되도록 데이터 흐름을 전면 수정 및 제어했습니다.

결론: 전체 웹앱의 문제 정의 수립, 예외 처리 시나리오의 유기적 종속 설계, 모달 세부 자가진단 및 재활 가이드의 전문 데이터 기획은 전적으로 본인의 논리적 주도하에 완성되었으며, AI는 오직 코딩 시공을 보조하는 도구로만 안전하게 활용되었습니다.
